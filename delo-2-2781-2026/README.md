## Как готовить к подаче

1. Распечатать каждый документ.
2. Вписать дату заседания.
3. Подписать каждый экземпляр.
4. Комплекты: суду + по числу сторон (для Ванюкова — суд и ответчик; для клиники — суд, ООО, Рыжевская).
5. На заседании сначала подать **уточнение требований**, затем возражения/ходатайства.

## Рекомендованная денежная конструкция

- Ванюков: 300 000 руб.
- ООО + Рыжевская солидарно: 300 000 руб.

Если суд упрёт в «задвоение» относительно исходных 500 000 — можно уменьшить каждое требование до 250 000 (ст. 39 ГПК РФ) прямо в заседании.
